# Code of Conduct

Bandage is maintained as an open source project for the scientific community. I want the issue tracker, pull requests and other project spaces to be respectful and useful for everyone.


## Expected behavior

Please be respectful of other users and contributors. Good-faith questions, bug reports and feature discussions are welcome. Disagreement is fine, but personal attacks, harassment, discriminatory language, sexualized comments or repeated unwanted contact are not acceptable.


## Reporting problems

To report unacceptable behavior, contact the project maintainer at rrwick@gmail.com. Please include a short description of what happened, when it happened, and any relevant links or screenshots. Reports will be handled privately and as promptly as possible.


## Enforcement

The maintainer may edit, hide or delete comments; close issues or pull requests; block users from project spaces; or take other reasonable action to keep the project spaces respectful and productive.


## Scope

This code of conduct applies to project spaces including GitHub issues, pull requests, discussions, documentation and any other public communication connected to the project.
